- Every FR-49..FR-60, NFR-9 and amended requirement traces to a story.

## Decisions needed from the owner

- **D1. Transition and breach events (high, blocks 21-1).** AD-27 puts the outbox "in the same transaction as the family commit". Today transition and breach records are file appends (`instance.log`, `breaches.log`), and only usage commits to SQLite.
  - Either (a) add `transition_events` and `breach_events` tables written in the writer's transaction, with the files becoming best-effort mirrors and `resync_events` reading SQLite;
  - or (b) keep the files as the source of truth and record the order (file append, then the DB commit carrying the outbox row) plus a restart rule for an event that reached the file but not the outbox.
- **D2. The writer and the coarse mutexes (medium, blocks 21-1).** Record:
  - whether callers may hold the Registry mutex while they wait for the writer's ack;
  - the bound on that ack wait;
  - who executes process Breach Actions once the AD-7 pipeline runs in the writer;
  - how the 19-2 wire-fence flag gets flipped.
- **D3. The Operator surface for labels, bindings, routes and announce credentials (high, blocks 21-3 partially and 23-1).**
  - FR-49, FR-51 and FR-60 require an Operator-only label verb and Control API call.
  - AD-20 and AD-26 store binding rows, routes and per-binding credentials.
  - No story or Control API resource creates any of them.
  - Proposed: `hekma label` and `hekma binding` nouns with matching `/v0/` routes, the label part owned by a story before 21-3 and bindings by 23-1.
- **Q9 interim (medium).** 21-3 must store a Scent-Check default before 22-3 decides Q9. An interim rule such as "`off` until 22-3" unblocks it.
- **Q11 interim (medium).** FR-60 already applies Policies to current Runs, so the interim rule is to follow the latest Policy. Record that, and record what a Policy change does to an open Run.
